**Tech Stack:**

## Global Constraints

- **AWS:** region `ap-southeast-1`, profile `lusot`, and every AWS CLI call passes `--no-cli-pager`. A `CreateOAuth2Token ... INVALID_REQUEST` error is transient here: retry once.
- **Model IDs:** exactly `sam-3.1`, `muse-spark-1.3` and `muse-voice-transcribe-1.0`. `muse-spark-1.3-contributor` is never used.
- **The face blur comes first.** Every image sent to Meta passes through it, and the client accepts only `BlurredImage` (C37).
- **The Meta key:**
  - It is never printed, logged or written to a file.
  - Code reads it from the `MODEL_API_KEY` environment variable.
  - In this session, the shell sets that variable from the Windows user variable in the same command: `$env:MODEL_API_KEY = [Environment]::GetEnvironmentVariable('MODEL_API_KEY','User')`. The process copy is a stale single character (F5).
- **What never enters the repo:**
  - account IDs, the Meta Team ID, console links or email addresses
  - plan text
  - photos other than test fixtures that are public domain or synthetic
- **Sealed data and private photos:** nothing under a `sealed` path is ever opened or listed. No Set A or A-neg photo is used. Probe photos are STURM-FloodDepth only (C12).
- **Data directory:** `LUSOT_DATA_DIR`, defaulting to `C:\Systems\Lusot\lusot-data` when unset.
- **Queue and concurrency:**
  - no reserved concurrency
  - SQS event source `MaximumConcurrency: 5`
  - visibility timeout of at least 6× the Lambda timeout
  - DLQ after 5 receives, with an alarm
  - S3 events only on `raw/`
- **Meta calls:**
  - Retry only on 429, 500 and 503: base 0.5 s doubling, plus up to 1 s of jitter, at most 4 attempts, honouring `Retry-After`.
  - Stream SAM. On a 504, fall back to `background: true` with polling.
  - Muse Spark sets `strict: true` in `text.format`.
  - The OpenAI SDK runs with `max_retries=0`, so only our retry rule applies.
- **Voice WAV:** mono, 16-bit PCM, 16 kHz.
- **Screen copy:**
  - Every screen shows exactly: `Lusot estimates depth at one spot. It is not advice to cross. Follow MMDA and local advisories.`
  - The word "safe" never appears.
- **Toolchain:**
  - Python `>=3.13,<3.14` through uv; Node 22; TypeScript `strict: true`.
  - Library versions are pinned in lockfiles. Check each library's current API with Context7, or with `dev.meta.ai/docs` for Meta, before calling it.
- **Commits:**
  - Conventional Commits, ending with these two trailer lines:
    ```
    Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
    Claude-Session: https://claude.ai/code/session_01APg5f7uACjpJWbzKxrpBcx
    ```
  - Never `--no-verify`. If the secret hook blocks a commit, fix the cause.
- **Builds:** Docker image builds and Gradle builds never run at the same time.

## Review Focus

1. **Wrong file type or size.** A non-JPEG or an over-10 MB upload must be refused by S3 itself, through the presigned POST conditions, not just by the app (Task 8 smoke: a PNG `Content-Type` gets 403).
2. **Bad capture data.** Location permission denied, or a phone clock more than 15 minutes off, must give the person a clear message, and nothing is uploaded (Task 9 tests; Task 6 tests for 422).
3. **Duplicate events.** A duplicate or retried S3/SQS event must not re-process a finished report. A failed raw-photo deletion is retried without re-analysis (Task 7 tests).
4. **The stale key.** The one-character process key must fail with a clear "missing or too short" error, without echoing it (Task 4 test).
5. **Stop switch.** If the switch can't be read, uploads stop (fail closed, 503) rather than silently continuing (Task 6 test).
