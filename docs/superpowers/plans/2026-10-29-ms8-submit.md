**Files:**
- Modify: `scripts/check_history.mjs`, `scripts/check_history.test.mjs` (MS7's)
- Create: `scripts/history-allow.json`

**Interfaces:**
- Consumes, from MS7's Task 7a:
  - `scanText(text, { planNumbers })`, with the rules `twelve-digit`, `plan-24`, `email` and `console-link`
  - `authorDomains(refs, git)`
  - the CLI `node scripts/check_history.mjs [--refs main] [--plan PATH]`, whose hit lines read `<short commit>:<path> <rule>` and `<short commit> message <rule>`
- Modifies: `historyBlobs(refs, git)`, which reads every blob as it lists it. It now applies the path rules to each path first, and never reads a blob that a path rule decides.
- Produces: the CLI options `--allow <json>` and `--export`. With `--export`, a missing or unreadable `--plan` file exits 2 instead of skipping the `plan-24` rule.
- Produces: the new rules:
  - **`plan-text`:** more than 5 whole plan lines of 60 or more characters in one blob, by `check_no_plan_leak.py`'s rule
  - **`never-commit`:** a path named `.env` or `.env.*` (but not `.env.example`), `samconfig.toml`, or any `*.jks`, `*.keystore`, `*.apk`, `*.aab`, `*.7z`, `*.pem` or `*.p12` file; or any path with a part named `sealed`, in any case. It is decided from the path before any blob is read, and such a blob is never read. A `sealed` hit is reported by commit and count only, never by path, since a file name there could say what it holds.
  - **`image`:** a `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.heic`, `.bmp`, `.tif` or `.tiff` path outside `allow.images`
- Produces: `authorDomains` also counts tagger addresses, and the summary line adds `<s> Claude-Session trailer(s)`.
- Produces: `scripts/history-allow.json`, shaped `{ "images": [glob, ...], "blobs": [{ "rule", "blob", "path", "reason" }] }`. A hit whose blob and rule are listed is reported as allowed, with its reason, and doesn't change the exit code. **No output line ever holds a matched value.**
