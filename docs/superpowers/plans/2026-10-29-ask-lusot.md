# Ask Lusot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Draft: written before Rene approved the spec (D7).** It follows the spec's calls (C700 to C735) and the defaults of AskL-Q1 to AskL-Q11. Revised on Oct 29 evening for its accuracy review, under Window 4's rulings (both kept in the git-ignored `.superpowers/` as `ask-review-1.md` and `ask-rulings-1.md`; the spec's §14 summarises them). If Rene changes a default, the tasks it names change with it, as "Execution notes" says. Window 4 builds it on Nov 2; Task 0 re-reads MS4's and MS5's merged code first, since the names below follow their drafts.

**Goal:** Ask Lusot answers typed and spoken Taglish questions about flood depth near a place, from published pins only, through one Muse Spark tool call, within 10 s or with the plain list.

**Architecture:**
- **The API Lambda** (Node.js 22, TypeScript, Vitest) gains `POST /ask` and `POST /ask/voice`. A small agent loop sends the question to Muse Spark with one tool, `get_reports`; code resolves the place (spot list, then Nominatim), reads pins through MS4's `pins.ts`, checks the model's JSON, and returns data, never prose.
- **The app** (React, MS5's string tables) renders every answer line, records WAV with Web Audio, and adds the Ask screen in MS5's fifth slot.
- **The template** gains the two routes, the model key grant, a 15 s timeout, a fourth stop switch and an alarm on the question cap.

**Tech Stack:** TypeScript 7, the `openai` npm SDK pointed at `https://api.meta.ai/v1`, AWS SDK v3 (DynamoDB, SSM), Vitest, React 19 with Vite 8, Playwright, Python 3.13 with uv for the probe and the spot list script, pyosmium for the OpenStreetMap extract.

**Spec:** `docs/superpowers/specs/2026-10-29-ask-lusot-design.md`. The plan argues from it, and the spec wins where they differ.

## Global Constraints

- **CLAUDE.md holds throughout:**
  - **Copy:** never "safe" or "unsafe", or any word containing "ligtas"; no crossing or travel advice; only "at this spot"; only the 9 levels and MMDA's 3 classes; the exact screen line on every screen; Rene reviews every new line (M20). New names (files, functions, tests, keys) avoid every banned form too, so the screen line's helpers are named after the screen line (the tracker's ruling, Oct 29, 9:50 PM by the tracker's clock).
  - **Meta:** only `muse-spark-1.3` and `muse-voice-transcribe-1.0`, never `muse-spark-1.3-contributor`; retries only on 429, 500 and 503, with backoff, jitter and `Retry-After`; prompts and schemas in versioned files; WAV only for transcription.
  - **Keys and logs:** only Lambda reads the key, from SSM; never print or log a key; never log a photo, an exact location, an IP address or a device id.
  - **Nominatim:** only from the API Lambda, at most 1 request a second, with our User-Agent and its cache. No script on the laptop ever calls it.
  - **Data:** never open, list or search a folder named `sealed`, and never open a Set A or A-neg photo or log. Every script that reads `LUSOT_DATA_DIR` refuses a path with a part named `sealed` (C66's rule).
  - **Infrastructure:** one template, `ap-southeast-1`, no reserved concurrency, deploy only as `rene-dev` with `--profile lusot --no-cli-pager`.
- **Exact values (the spec):**
  - **Search:** 300 m; a window of 180 minutes at most, clamped to 1 to 180; at most 5 live reports and 3 demo pins in an answer, and the same 5 and 3 as summaries sent to the model.
  - **Budget,** from the handler's start: transcription by 4,000 ms; the model by 7,500 ms; the answer by 8,500 ms. A second model turn needs 1,500 ms left, Nominatim needs 2,500 ms left, and one Nominatim call gets 1,500 ms. The API function's timeout is 15 s.
  - **Caps:** 20 questions per device and 300 in all per UTC clock hour, the device first. Codes `question_limit` and `question_cap`, each a 429 with `Retry-After` in seconds to the next hour.
  - **Requests:** a question of 1 to 300 characters once trimmed; `here.accuracyM` from 0 to 100; a voice body of at most 1,100,000 bytes; WAV mono, 16-bit PCM, 16,000 or 24,000 Hz, 0.5 to 15 s.
  - **Model calls:** `store: false`, `include: ["reasoning.encrypted_content"]`, `reasoning.effort` from Task 2's ruling (`minimal` by default), `parallel_tool_calls: false`, `tool_choice: "auto"`, `max_output_tokens` 800; at most three turns and two tool calls. Transcription with `mode: "PUSH_TO_TALK"`, `languageBias` from Task 2's ruling (`["Tagalog", "English"]` by default), and the spot names as `keywords`.
  - **Nominatim:** `/search?format=jsonv2&limit=1&countrycodes=ph&bounded=0&accept-language=en&viewbox=<NCR bounds>`; a cache of 7 days for a found place and 1 day for a miss, read with `GetItem` and checked against its own `expiresAt`; a slot item per epoch second in `limits`, holding its write time in milliseconds, with a 2-hour TTL, and a request only when the previous slot was written at least 1,000 ms earlier; the place string trimmed to 100 characters, control characters removed.
- **Names (spec §5):**
  - **Answer fields:** `source`, `fallback`, `kind`, `crossing`, `vehicle`, `place`, `windowMin`, `radiusM`, `count`, `reports`, `demo`, `deepestId`, `cited`, `suggestions`.
  - **Values:** source `model`, `plain_list`; fallback `model_calls_paused`, `deadline`, `model_error`, `key_rejected`, `invalid_answer`, `no_tool_call`; kind `reports`, `no_reports`, `place_too_broad`, `no_place`, `lookup_unavailable`, `outside_metro_manila`, `no_location`, `off_topic`, `no_speech`; vehicle `light`, `heavy`, `on_foot`; place source `spots`, `nominatim`, `here`.

  - **The switch:** `/lusot/stop/nominatim`, beside MS1's three.
  - **Files:** `backend/api/prompts/ask_v1.md`, `ask_v1.tools.json`, `ask_v1.offtopic.json`, `ask_v1.answer.json`, `ask_v1.words.json`; `backend/api/src/data/spots.json` and `SPOTS_SOURCE.md`.
- **The log line** (spec §4.9): exactly the fields listed there, `final` included, in snake_case, and none of the never-list.

## Review Focus

1. **A second question sent while the first is still waiting.** One request in flight per screen; the first answer never appears under the second question. Test: Task 16, `a second send waits for the first`.
2. **The app goes to the background, or the screen locks, mid-recording.** The recording stops and is discarded, the microphone is released, and nothing is sent. Test: Task 15, `hiding the page cancels the recording`.
3. **Place names typed every which way:** "ESPAÑA COR MACEDA!!", "espana cor maceda", "España corner Maceda", "España & Maceda". All find the same spot. Test: Task 4, `spellings of one corner find one spot`.
4. **Two Lambdas asking Nominatim in the same second.** One request goes out; the other waits for the next second or answers `lookup_unavailable`. Test: Task 5, `two geocoders in one second make one request`.
5. **"Use my location" on, with a slow or poor fix.** The app waits up to 10 s for 100 m or better, says why when it can't, and never sends a poorer fix. Test: Task 16, `a poor fix is never sent`.
